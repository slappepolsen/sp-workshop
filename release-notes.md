## Downloads
> #### Which download do I need?
> - **Windows:** Use **x64** on most PCs. Use **ARM64** only if the PC has an **ARM** processor. Check *Settings* > *System* > *About*.
> - **macOS:** go to *Apps* > *About This Mac*, if you see "*Chip:*" with M1 / M2 / M3 / M4 (or similar), use **Apple Silicon**. If you see "*Processor:*" with Intel i5 / i7 / i9 (or similar), use **Intel**.
> - **Linux:** Use **Linux x64** on normal 64-bit PCs; for ARM Linux, use your distro’s guidance (this build is aimed at x86_64).
